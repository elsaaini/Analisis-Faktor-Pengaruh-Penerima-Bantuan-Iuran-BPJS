# Analisis Faktor Pengaruh Jumlah Penerima Bantuan Iuran Badan Penyelenggara Jaminan Sosial Kesehatan di Indonesia Tahun 2019-2021 
## Latar Belakang
Proyek ini bertujuan untuk  mengidentifikasi pola hubungan di antara variabel-variabel yang berpengaruh terhadap jumlah penerima bantuan, sehingga dapat memberikan wawasan bagi pembuat kebijakan dalam meningkatkan efektivitas alokasi bantuan kesehatan di Indonesia.
## Dataset
Dataset yang digunakan dalam analisis ini dapat diakses melalui link berikut:

## Tools
* Excel
* RStudio
## Tahapan Analisis
1. Pembentukan Model
2. Uji Asumsi untuk Model 
   * Uji Hipotesis
   * Uji Overall
   * Uji Parsial untuk Konstanta
   * Uji Parsial untuk Koefisien 
3. Diagnostic Checking 
   * Variabel Independen bersifat Tetap
   * Linearitas Variabel Dependen dengan Setiap Variabel Independen Terpenuhi
   * Normalitas Residu
   * Homoskedastisitas Residu
   * Tidak Terdapat Autokorelasi Error
   * Tidak Memiliki Multikolinearitas
## Kesimpulan
Dengan menggunakan analisis regresi linear berganda diperoleh faktor yang memengaruhi jumlah penerima bantuan iuran BPJS Kesehatan adalah jumlah keluarga penerima bantuan sosial, jumlah keluhan kesehatan, dan jumlah keluhan kesehatan tidak terpenuhi.
